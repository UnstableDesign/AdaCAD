About Live Drafting

Live Drafting is a Hydra-style live-coding environment that sits on top of the AdaCAD weave draft making library. Edit TypeScript in the overlay editor. Play, pause, or step through your sketch and see the result as a fullscreen draft image behind the code. Pause and download a color image of the screen as well as a bitmap of the design for your digital loom. Import into AdaCAD to further adjust and generate a threading and tie-up for your dobby or shaft loom.

This has been mostly vibe-coded by Laura Devendorf in Cursor. The project defines functions that map to calls to the AdaCAD drafting library. Mess with it on GitHub to add new features.

Sketches are saved in your browser under livedrafting-sketch. Code runs locally via esbuild-wasm.

Available functions

Sketches are async TypeScript. Use top-level await. Structure builders return a LiveDraft you can chain (.stretch().fill().display()) or await as a plain Draft for the functional style.

Chaining example

const s1 = tabby(osc1, osc1, osc1, osc1);
const s2 = tabby(osc2, osc2, osc2, osc2);

await waffle(4, 3)
  .stretch(20, 20)
  .fill(s1, s2)
  .addColors([1, 2, 3], [7, 8, 9])
  .display(true, false);

Core (adacad-drafting-lib)

  • getOp(name) — look up an operation
  • call(op, params, inlets?) — run an operation
  • initDraft() / initDraftWithParams(params)
  • draft(existing) — wrap a draft for chaining
  • display(draft, use_color?, floats?) — draw a raw draft (functional style)

Animation

  • oscillator(min, max, options?) — frequency, phase
  • renderCount(multiplier?)

Structures → LiveDraft

  • twill(raised, lowered, offset, binding)
  • satin(repeat, shift, facing)
  • tabby(warps_raised, warps_lowered, base_pics, alt_pics)
  • waffle(float_length, binding_rows, packing_factor)
  • random(ends, pics, pcent)
  • interlace(drafts[], repeats?, weft_oriented?)
  • join(drafts[], repeats?)

LiveDraft chain methods

  • .stretch(weft, warp) · .shift(ends, pics) · .symmetry(options, remove_center?)
  • .addColors(weft_colors, warp_colors) · .tile(...) · .resize(width, height)
  • .fill(black, white) — black/white are LiveDraft
  • .display(use_color?, floats?) — terminal; draws to screen

Functional style (still supported)

  • stretch(draft, …) · shift(draft, …) · symmetry(draft, …)
  • addColors(draft, …) · tile(draft, …) · resize(draft, …)
  • fill(pattern, black, white) — each arg is a Draft (e.g. await waffle(4, 3))
